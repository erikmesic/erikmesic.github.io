Interrogating 'Common Knowledge' of LLMs Across Temperatures

Cross-institution research on LLM sentiment stability and sampling temperature effects.

Overview

Collaborated with professors and labs across CUNY and NYU on LLM stability research. The project implemented hierarchical models to quantify how sampling temperature affects sentiment outputs and developed robust variance analyses.

Methods

  • Hierarchical modeling with bootstrapping and permutation tests.
  • ANOVA-style variance analysis (Fligner-Killeen, Levene) and embedding-based similarity metrics.
  • Semi-synthetic data generation to seed analyses and ensure measurement stability.

Data & Scale

Designed to include millions of generated samples (9.76M expected) across models and temperature settings; used a structured SQL file storage and HPC resources for local model runs.

Preliminary Findings

Work-in-progress: validated analysis code and sampling pipelines; structured reproducible experiments for broader replication and publication.
